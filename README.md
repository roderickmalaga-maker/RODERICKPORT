## `💡` Developer Mindset

Software development, to me, is a cycle of:

1. **Learn** — understand the problem and the tools at hand  
2. **Build** — implement a working solution, however small  
3. **Mistake** — run into bugs, edge cases, and design gaps  
4. **Improve** — refactor, clean up, and try again  

I believe a good developer keeps iterating: write, test, debug, and refine. Growth comes from finishing what you start, learning from mistakes, and staying patient with the process.
